# Intel AI Studio -> LocArc

This repository is a **compatibility bridge**. The project has been renamed to **LocArc** and
now lives at:

**https://github.com/Asahi-Prv/locarc**

The releases here mirror LocArc builds under the pre-rename asset names
(`Intel-AI-Studio-*`) so installations of Intel AI Studio v1.14.x can update themselves
automatically. After updating, LocArc switches to the new repository for future updates.

Please use the LocArc repository for downloads, documentation, and issue tracking:
https://github.com/Asahi-Prv/locarc
